# Pong Game

A 2D Pong-style game built with Unity and C# as a personal game development project.

## Features

* Player-controlled paddle movement
* Ball physics and collision
* Score tracking
* 3-life system
* Game over and restart system
* Increasing ball speed
* Randomized ball launch direction
* Coin collection system
* Bonus score from collected coins

## Controls

* **W / S** — Move the paddle
* **Space / Any Key** — Start or continue the game
* **R** — Restart after game over

## Built With

* Unity
* C#
* 2D Physics
* TextMesh Pro

## Project Structure

The main gameplay scripts are located in the `Assets` folder, including:

* `BallMovement.cs`
* `PaddleMovement.cs`
* `GameManager.cs`
* `CoinMovement.cs`
* `CoinSpawner.cs`
* `TriggerZone.cs`

This project helped me practice:

* Player input and movement
* Managing game state
* Score and lives systems
* Creating and using prefabs
